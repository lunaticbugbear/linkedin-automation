# Source policy

official public/free API catalogs are valid sources unless there is a concrete quality problem.

## source provenance

Every record keeps source provenance: source name, URL, import date, and optional license.

## Verification

Prefer official docs. Use curated catalogs for discovery. Mark uncertain auth, CORS, or pricing as unknown rather than guessed.

## Rejection

Reject or downgrade sources only for a concrete quality problem such as broken docs, repeated invalid records, misleading licensing, or stale entries.
